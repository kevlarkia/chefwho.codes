# Profile: swm

Smart Workforce Movement is one domain this ledger can run, not the whole
toolkit. When `--profile swm` is set, the pipeline applies recovery-first
rules from the SWM extraction suite (`swm-recovery/prompts/`) without
turning the runtime into an SWM-only product.

Addendum for both TEMP-ARC calls:

- Operating mode is extraction, not canonization or publication.
- Canon labels (sealed, final, official) do not control inclusion.
- Do not resolve disagreements; keep CONFLICTING items unless they are
  fabricated.
- Process only authorized SWM / Okram / SigNEL / Hazel / OSH / SDRWM
  material in the supplied source.
- Isolate legal, medical, crisis, or private relationship material.
- Evidence labels must be exactly one of the TEMP-ARC-001 set.
