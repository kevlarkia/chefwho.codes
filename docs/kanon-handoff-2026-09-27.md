## The four laws

Taken from the instrument.

1. Preservation. Nothing is deleted. Doubt, disproof, and revision stay.
2. Objective. What sources can carry, the rule canonizes. There is no
   human gate.
3. Subjective. What is not provable waits for you to verify or reject.
   Verification does not rewrite it as objective.
4. Standing. Sources gain and lose standing. The bar moves with them. A
   human hold is not silently uncanonized when the bar moves.

Objective and subjective are decided at ingest by the rule, not by a
confidence cutoff. The scope is personal first. The pipeline is
source-agnostic so it can widen later without a rebuild.

The bar, as coded: floor 58, cap 80, young bar 64 until three seasoned
sources exist, seasoned at 50 or above. Eligible carriers are primary
and record. A witness can carry only at 70 or above. Press, self, and
hearsay inform only.

## What the site is

Six rooms: Canon, Desk, Sources, Enter, Ask, Books. The reader is not a
seventh room. It is a sidebar.

- Canon is what holds. Fallen claims stay visible.
- Desk is what the rule will not decide. Verify or reject.
- Sources carry standing. Standing can be raised or lowered. Sources
  are not deleted.
- Enter writes a claim, cites sources as supporting or contesting, and
  shows the ruling before it is committed.
- Ask is the pipe. Open any claim for its journey. Entries have no
  delete.
- Books is a shelf, not a set of claims.

The live record in the browser is this browser only, under the name
`kanon-v1`. Blanking clears sources and entries in this browser. It
does not clear the shelf, the talks, or the synopses. Bringing a copy
back replaces sources and entries only. It does not replace the shelf
or the talks.

## The pipe

Ask closes the question against the record before any model speaks.

- A held fact is said as held by the rule.
- A desk item stays "not canon."
- If the record does not contain it, the answer is: "That is not in the
  record. I will not supply it from anywhere else."
- A model may only rephrase the closed lines. If it adds a content word
  of length 5 or more that is not already in the lines, the question,
  the context, or a small glue list, the phrase is dropped and the
  lines themselves are kept.
- The model cannot write the record.
- An absent question never calls a model.

Checked against the specimen: "When did the Bodleian open to readers?"
answered 8 November 1602, held by the rule. "Do canon and cannon share
a root?" stayed on the desk.

Keep a copy downloads a file of kind `kanon-copy`. It holds sources,
entries, whether this browser was blanked, and whether the specimen is
still the load. The journey is inside the entries. The file is not
changed when it is brought back. That file does not hold books, talks,
synopses, or the voice choice.

Until a Cloudflare account is connected, the mouth is under that same
limit. If no model is connected, the lines themselves are the answer.
If a model tries to add something, the voice is refused and the lines
are kept.

## Reader

27 September. Mark a word or a short phrase in the page. A sidebar
opens. It shows the definition held now, then the origin. It does not
wait for a second tap.

- If the word is in the base held here, that definition is the one
  shown, marked "Held here." The wider dictionary is not allowed to
  overwrite it.
- If it is not held here, the wider base is asked. A returned
  definition is marked "From the wider base."
- An origin is shown only when this base has one, or when the wider
  base actually returns one. Otherwise the sidebar says the origin is
  not in the base. Nothing is invented.
- If the wider base does not answer, the sidebar says it is
  unreachable. It does not pretend the word is unknown.
- Close, or mark another word. Say it speaks the word. It does not
  speak on its own. A recording is offered only when the wider base
  returns an https address.

The held base is the list in the instrument. It is not a dictionary.
